# IceAndFlame-Updates

Публичный репозиторий обновлений для **ICE AND FLAME — русификатора World of Jade Dynasty**.

Здесь находится только служебный `manifest.json`. Готовые версии патчера и русификатора будут публиковаться через GitHub Releases.

- Версия патчера задаётся отдельно.
- Версия русификатора задаётся отдельно.
- Имена игровых `.pak` не меняются между версиями.
- Перед установкой патчер будет проверять SHA-256 скачанных файлов.

## Публикация новой версии русификатора

1. Положить новые файлы в папку package\:
   - ~RU_PATCH_1_P.pak
   - ~RU_QFONT.pak
2. Запустить RELEASE_TRANSLATION.cmd.
3. Ввести новую версию, например 4.09.29.

Скрипт сам обновит локальный main, проверит GitHub CLI, посчитает SHA-256, создаст GitHub Release translation-X.XX.XX, загрузит оба .pak, обновит manifest.json, закоммитит его в main и проверит публичный manifest.

Файлы из package\ в Git не добавляются.
