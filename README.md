# IceAndFlame-Updates

Публичный репозиторий обновлений для **ICE AND FLAME — русификатора World of Jade Dynasty**.

Здесь находится только служебный `manifest.json`. Готовые версии патчера и русификатора будут публиковаться через GitHub Releases.

- Версия патчера задаётся отдельно.
- Версия русификатора задаётся отдельно.
- Имена игровых `.pak` не меняются между версиями.
- Перед установкой патчер будет проверять SHA-256 скачанных файлов.
